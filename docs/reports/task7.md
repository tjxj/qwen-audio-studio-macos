# Task 7 — 原生参考音频

完成 WAV、MP3、M4A、OGG Opus 原生导入、完整源试听、手动选区试听、mono PCM16 WAV 裁剪、质量提示、暂存/主动保存、本地音色库与任务租约。默认临时片段空闲一小时且没有租约才清理；源文件只读，脚本中的音色槽位不会静默绑定到新声音。

## 验证

- 修复轮最终完整串行测试原始摘要：`119 tests passed after 15.249 seconds`；原有真实输出目录对话框测试按其独立宿主策略跳过。初轮并行曾触发既有自动保存测试的调度时序断言，串行复核通过。
- 四种合成 codec 夹具通过真实解码。40秒 WAV 的12–18秒选区为6秒；40秒 Opus 的34–40秒尾部选区完整保留。
- 0/30秒边界、越界/非有限时间、源超大/超长、容器错配、原文件不变、质量提示、库重开与篡改、两任务租约及释放后的空闲期限均已验证。
- 已签名 release `.app` 通过独立有界原生宿主验证。试听使用零音量，验证源/选区/停止状态切换；未进行人耳听感验收。
- 1280×720窗口内850×600 sheet，浅/深色2倍截图及检查记录在 `docs/qa/reference-audio/`。原生滑杆 target/action、右方向键、辅助标签与外部时间数值同步均由真实控件验证。
- 最终二进制 `minos 14.0`，只有系统动态库依赖，codec 静态链接；三份上游COPYING随签名应用交付。

## 审查修复

- 临时清理先在同一事务内检查空闲期限/租约并登记持久清理记录，再移除可用音色登记。文件删除失败会保留清理记录，跨数据库重开继续重试；文件已删、确认未写回的崩溃窗口也可恢复。已验证权限失败、重试、租约保护和禁止重新登记待删ID。
- 导入改为64 KiB源复制、原生Opus文件流、最多8192帧转换缓冲及PCM16分块写出；每块释放临时Objective-C对象，质量统计也增量计算。独立进程600秒Opus压力验收峰值为10,977,280字节，低于160 MiB上限；最后594–600秒的独立880 Hz信号测得880.0 Hz，长度6秒。
- 修改起止点后自动分析当前选区，保存前再次检查。静音/削波会先显示提示，再由“仍然使用此片段”继续；正常音频直接保存。实际应用提示态截图为 `docs/qa/reference-audio/voice-warning-1280-sheet.png`。

## 构建

先运行 `bash scripts/build-native-codecs.sh`，再运行 SwiftPM测试。`zsh scripts/build-app.sh` 会自动准备静态库。脚本校验固定版本官方源包的SHA256；详细版本、许可证及夹具说明见 `ThirdParty/README.md`。只有开发夹具生成脚本使用ffmpeg，已安装应用无需外部解码程序。

## 已知边界

- 构建首轮支持Apple Silicon；macOS14为部署下限，仍需该系统版本的真机验收。
- OGG Opus链式多逻辑流显式拒绝，普通单逻辑流已通过实际应用验证。
- Task8需要将参考试听与结果播放器统一或互斥，保持全应用单路播放。
- QA覆盖原生控件呈现及控制器范围设置，人工键盘/拖动和VoiceOver体验待整机验收；生成按钮与持久草稿整合由后续任务完成。
