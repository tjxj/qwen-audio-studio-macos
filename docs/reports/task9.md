# Task 9 — 原生应用接线与界面验收

状态：已完成本阶段实现；真实收费调用、旧版迁移与 DMG 归 Task 10。

## 已接通的功能

- 应用启动持有一个 `StudioStore` 与进程锁。草稿、42 个内置模板及自建/收藏、输出目录、音色库、生成服务和播放控制器共用该生命周期；库被其他实例占用时显示明确错误，不开启假持久化工作区。
- 草稿自动保存、当前项目选择与重启恢复。创作台保留七种模式、脚本、音色、输出设置；空白草稿藏于低强调菜单。1–3 个候选经过真实预检与逐次收费确认后提交，显示数据库中的任务阶段，可取消未领取的排队候选。
- SQLite v5 为生成记录加入名称、收藏、备注、创建时间、最终版本和项目归档；原有项目、任务、资产 ID 不变。作品库显示生成/项目/回收站，支持搜索、类型/状态/时间/收藏筛选与稳定翻页、试听/A-B、导出音频/脱敏报告、Finder、复制 Prompt、继续创作、可恢复删除与归档恢复。缺失或无法解码的音频禁用试听、下载及 Finder，并提供目录重新授权入口。
- 模板自建、收藏、删除撤销与重启恢复；数字变量输入 `-`、空值、`1.` 期间保持原字符串，仅在保存时校验。
- 设置独立双栏：API Key 与 Workspace ID 分字段写入本机钥匙串，保存后不回填密钥；北京地域官方获取帮助、文件夹、格式、采样率、候选数、同时生成 1–3 路、主题/字体及本地免付费环境检查。
- 候选并发调度在同一持久批次内限制 1–3 路。确认 nonce 幂等、每候选恰好一次 POST、取消仅影响 queued、网络结果不确定不自动重发、共享参考音色租约在请求期间保持有效；默认安全值为 1 路。

## 自动验证

- 本机权限下 `scripts/verify-output-folders.sh`：审查修复后串行完整 166/166 通过；系统 `NSOpenPanel` 取消测试独立 1/1 通过；release `.app` 经本机临时签名并通过严格验签。全套中系统对话框一项按设计跳过，在独立阶段执行。一次冷启动面板耗时超过旧 25 秒边界，测试宿主超时已调整，最终独立测试通过。
- 新增重启草稿/旧项目选择/模板持久化与撤销、SQLite 作品元数据/筛选/日期/翻页、设置默认值、数字中间输入、稳定音色槽位确认及阻塞假 provider 并发/取消/未知结果/引用租约测试。全部使用合成数据；自动化未发送真实模型请求。
- UI 自截使用签名原生 `.app`、临时隔离 SQLite 库及合成音频。创作台、作品库、模板在 1280×720 和 1120×720 浅/深模式均保存 2× PNG，窗口无整体滚动；作品列表、模板列表和脚本区各自内部滚动。结果页另有浅/深 1280×720 的三版本合成音频校验图。设置为独立 780×590 内容窗口，自截宿主总尺寸 780×642，故 `settings-*-1120/1280.png` 文件名指截图轮次，实际尺寸以 `settings-window-checks.txt` 为准；设置无整页滚动。

截图与每页像素/窗口记录位于 `docs/qa/task9/`。例如 `creation-light-1120.png` 为 2240×1440，`library-dark-1280.png` 为 2560×1440。设置截图的 Keychain 演示模式未读取真实凭据；所有屏幕素材均为合成数据。

## 审查修复

- 生成历史的模式、名称、脚本与筛选均读取提交时冻结的 `BatchSubmission.project`；继续创作仍取项目的当前修订。后续项目改名、归档或改模式不会改写历史记录。
- 最终版本写入后在作品列表和结果页显示徽章并即时刷新。作品库的生成视图可见时按 1 秒间隔刷新；当前筛选隐藏运行任务时仍能呈现随后匹配的结果。轮询保留未提交的名称/备注输入、已展开的分页与游标；编辑中选中的记录若暂时不匹配筛选，会显示“正在编辑 · 暂留”并保持可保存，同时更新其真实任务状态。界面消失即取消轮询；项目/回收站视图与加载中不发起轮询查询。
- 新提交开始即清空旧批次 ID 和阶段；受控提交延迟测试确认旧批次不能被新任务的取消按钮误取消。
- 对存在有效已登记下载回执的失败/中断记录显示“仅重试下载”，从记录中复用 GET，不重发收费 POST。设置分列应用数据（SQLite/WAL/SHM 与本机音色）和已登记生成文件（音频、Prompt、报告，含回收站）的实际字节占用；只按数据库登记路径与 inode 校验后统计，不遍历或计入用户输出文件夹内的未登记文件。失效授权或缺失文件显示不可统计数。
- 深色结果页的最终版本和验收标识使用高对比浅绿，底栏指标说明使用更易读的浅色。
