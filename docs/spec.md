# Qwen Audio Studio for Mac — 原生版规格

状态：2026-09-24 已获用户同意开发。现有网页版保持独立运行。

## 产品边界

- 目标：面向 macOS 14+ 的 SwiftUI/AppKit 原生应用，交付可本机安装运行的 DMG。首轮验收硬件为当前 Apple Silicon Mac。
- 运行时不得启动浏览器、本地 HTTP 服务、Python、Node 或 ffmpeg；界面、网络、存储、音频均在编译后的原生进程内。
- 模型固定 `qwen-audio-3.1-tts-next`，北京地域。生成仍需联网，文本及经逐次确认的参考音频发送至阿里云。
- 主窗口默认 1400×860，最小 1120×720；在 1280×720 完成主要创作操作，窗口内容不整体滚动。长脚本只在编辑器内滚动。右侧检查器保留常用项，高级设置使用原生 sheet。
- 视觉延续浅底、白面板、墨绿强调；支持浅色/深色/跟随系统。标题与脚本使用内置的、依法更名的思源宋体子集；控件使用 macOS 系统字体。尊重键盘导航、VoiceOver、减少动态效果。
- 首版不引入登录、云端同步、视频生产、多轨编辑或自动更新。

## 信息架构

侧栏仅有创作台、作品库、灵感模板。设置/帮助位于侧栏底部。音色入口在创作台。

创作台在同一窗口内显示可编辑名称与保存状态、七个创作模式、脚本、声音与常用参数、目标文件夹、候选数和生成按钮。无“当前工作流”说明区，无醒目的“新建项目”按钮。空白草稿入口放在低强调菜单。

作品库含生成、项目、回收站三个视图。生成记录可试听/下载/查看详情/筛选/重命名/收藏/复制 Prompt/在 Finder 显示/继续创作/A-B/可恢复移除；运行中记录按真实阶段显示并约束取消。结果页提供全部版本、最终版本、备注、真实验收字段、同位置 A/B、定位、音量与至少 0.5 秒循环选区。任何时候只有一路音频可听。

模板库含七类各六个内置模板，保留旧模板 ID，支持变量填写、服务端等价的本地预览、收藏、自建/编辑/移除、覆盖确认与撤销。模板只提供建议时长，不能冒充实际时长。

设置包含 API Key、Workspace ID、官方获取帮助、默认输出、默认参数、外观、并发数、存储占用与本地环境检查。密钥只在本机 Keychain；屏幕不回填明文。环境检查不调用收费模型。

## 领域与任务规则

- `GenerationParams` 与旧版一致：WAV/MP3/PCM，8/16/24/44.1/48 kHz，1/2 声道，音量、语速、Seed、MP3 编码和 AIGC 标记。所有组合在云端请求前校验。
- 编译后的 Prompt ≤ 3000 Unicode code points；角色与音色按稳定 ID 绑定。原稿里的 `@voiceN` 移除/重排后必须报错，绝不重新绑定到另一段声音。
- 默认一候选，最多三候选，Seed 各不相同。预检展示最终 Prompt、文件与本次调用次数，再由用户确认可能收费的提交。
- 每次提交有持久 `clientRequestID`。同 ID 同内容只返回旧批次；同 ID 不同内容报冲突。云端请求超时/断线后状态为结果不确定，禁止自动重发收费请求；下载重试可使用已得到的 URL。仅尚未领取的排队任务可取消。
- 后台阶段：queued、preparing、requesting、downloading、validating、success/failed/cancelled/interrupted。提供方未给进度时不显示虚构百分比。
- 重启时运行/排队中的旧任务标为中断，保留快照且不自动再次收费。

## 音色与文件

- 接收 WAV、MP3、M4A、OGG Opus 原始输入；源文件 ≤ 50 MiB、≤ 10 分钟。若系统不能直接解 OGG/Opus，则内置必要的原生解码代码或库，不要求用户安装额外程序。
- 用户手动选起止点；云端成品片段 `0 < duration ≤ 30s`、≤ 10 MiB，单声道 PCM16 WAV。原文件不被覆盖、不静默截前 30 秒。
- 展示时长、采样率、声道、质量提示（静音、音量与削波）。质量提示不冒充声纹相似度判断。
- 默认临时保存；仅用户主动选择后进入本地音色库。临时文件空闲一小时且没有任务租约才可清理。每次云端生成独立展示文件名/时长并确认本次上传。
- 输出目录由 `NSOpenPanel` 选择，以安全作用域书签持久访问；取消不改当前设置。提交时锁定目录快照，生成音频/Prompt/报告放在唯一任务目录。Finder 只能打开已登记目录和资产。任务删除仅移动应用拥有的生成文件，可恢复且不会覆盖同名文件。

## 数据与旧版导入

- 原生应用自己的 SQLite 位于新的应用数据目录；生成文件和用户选择的输出目录独立。凭据写新 Keychain service，支持用户明确授权的旧凭据读取或手动填写。
- 原生库包含项目 revision、任务与批次、资产、参考音色与租约、模板/收藏、目录书签和可恢复回收记录。SQLite 启用 WAL、外键、busy timeout；写事务不等待云端和解码。
- 首次导入向导请求用户选择旧版目录。读取旧版 SQLite/历史 JSON，只读复制且先备份。校验项目、任务、资产数量、ID 和最终版本关系。旧版音频文件保持原样；引用外部位置须获得用户文件夹授权。两个应用不同时写一个数据库。
- 碰到损坏元数据、缺音频、无目录权限，应记录可操作错误；不能静默丢弃记录并宣布迁移成功。导入失败不激活半成品数据库。

## 工程与验证

- 使用 Swift Package（StudioCore + 原生 App）及可在 Xcode 打开的工程；无网页构建产物。
- 核心采用 Swift Testing/XCTest 测真正的 SQLite 事务、Prompt 编译、URLSession 请求构造、幂等、音频解码和文件移动；假 provider 负责自动化，真实 Next 只做明确数量的短句冒烟。
- 原生界面做键盘/VoiceOver与四个窗口尺寸视觉验收，保存 Retina 截图。测试音频标记为合成素材。
- 构建 `.app`，制作含“应用程序”快捷方式的 DMG；本机版先交付。若需供其他人直接下载使用，再经用户现有 Developer ID 证书签名、公证及贴票；构建脚本不得保存证书密码或 API Key。
